NewLife.Video ofrece multiplexación, demultiplexación y transcodificación para H.264/H.265, MP4, FLV, RTMP y RTSP, orientado a streaming y videovigilancia.

## Instalación

```bash
dotnet add package NewLife.Video
```

## Inicio rápido

```csharp
var reader = new Mp4Reader(stream);
var frame = reader.ReadFrame();
```

## Características

- Capacidades de streaming y comunicación en tiempo real
- Amplia cobertura de versiones de protocolos y formatos
- Multiplataforma: Windows, Linux, macOS y ARM64/LoongArch64
